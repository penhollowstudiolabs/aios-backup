# Deferred-map direction capture

## Pattern

When Avi sets a future operational priority while explicitly not working that evening, preserve the decision as a dated source capture in `Atlas/_Inbox/`; do not treat it as authorization to revise the Workboard or Re-Entry immediately.

## Example decision shape

- Priority: conduct a bounded operating-map truth pass first.
- State change: a council is paused/concluded after its first round because Avi has enough to proceed without further rounds.
- Boundary: no further council relay, model override, or implementation until Avi explicitly reopens it.

## Later map-session use

Use the capture as evidence to mark the council historical/paused and correct stale live-state references while retaining the original launch/decision record.
